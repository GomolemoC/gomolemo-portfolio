University Academic Management Database

MySQL Database Design SQL

📋 Project Overview

Designed and implemented a comprehensive MySQL database system for university academic management. This project demonstrates my understanding of relational database design, normalization, and complex query optimization.

🎯 Why I Built This

As a student, I noticed the complexity of managing academic records. I wanted to create a system that could handle student enrollment, course management, and academic tracking efficiently.

💡 What I Learned

  • Database normalization (3NF) and why it matters
  • Complex JOIN operations and subqueries
  • Stored procedures and triggers for automation
  • Index optimization for performance
  • Real-world database design challenges

🔧 Technical Implementation

CREATE TABLE students (
    student_id INT PRIMARY KEY AUTO_INCREMENT,
    registration_number VARCHAR(20) UNIQUE NOT NULL,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    enrollment_date DATE NOT NULL,
    department_id INT,
    cgpa DECIMAL(4,2) DEFAULT 0.00,
    FOREIGN KEY (department_id) REFERENCES departments(department_id)
);
